# Hotel Booking Data Visualization

## Overview

This project focuses on visualizing different aspects of hotel booking data using Seaborn and Matplotlib. Various visualization techniques are used to represent booking characteristics, customer information, cancellations, and other features of the dataset.

## Visualizations

The project includes different types of visualizations such as:

- Count plots

- Bar plots

- Line plots

- KDE plots

- Box plots

- Heatmaps

- Categorical plots

- Faceted categorical plots
